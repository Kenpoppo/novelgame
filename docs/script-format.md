# 台本フォーマット仕様

`parseScript()`([shared/domain/parser.ts](../shared/domain/parser.ts))が
解釈する独自の簡易スクリプト形式。

現在の一次的な作成手段はブラウザGUIエディタ(`/editor`、詳細は
[editor.md](./editor.md))だが、このテキスト形式も引き続き有効。
上級者が直接テキストで書きたい場合の代替経路であり、また
`shared/domain/project/sample-project.ts` がエディタ初回起動時のシード生成に
このパーサーを使っている(サンプル本文は
[shared/domain/scripts/sample-script.ts](../shared/domain/scripts/sample-script.ts)
に文字列定数として持つ。`?raw` インポートはNitro(サーバー)側のビルドで
解決できなかったため採用していない)。

行単位で解釈される。空行は無視される。

| 記法 | 意味 |
|---|---|
| `# コメント` | コメント行(無視される) |
| `@char id 表示名 [色]` | キャラクターを登録する。`色` は省略可(CSS の色指定、例: `#4fc3f7`) |
| `id: セリフ` | 登録済みキャラクター `id` の発言として表示 |
| それ以外のテキスト行 | ナレーション(地の文)として、名前なしで表示 |
| `*label名` | ジャンプ先ラベルを定義する(表示上は何も起きない) |
| `-> label名` | 指定ラベルへ無条件ジャンプ |
| `?` | 選択肢ブロックの開始。直後に連続する `>` 行をまとめて1ブロックとする |
| `> 選択肢テキスト -> label名` | 選択肢の1項目。選ばれると `label名` へジャンプ |

## 例

```
@char taro 太郎 #4fc3f7
@char hana 花子 #f48fb1

夏の日差しが差し込む教室。

taro: おはよう、花子。
hana: おはよう、太郎くん。今日もいい天気だね。

?
> 公園に誘う -> park
> 図書館に誘う -> library

*park
taro: じゃあ、公園に行こう。
-> ending

*library
taro: じゃあ、図書館に行こう。
-> ending

*ending
放課後、二人は連れ立って歩いていった。
```

## 注意点

- `id: セリフ` の `id` が `@char` で登録されていない場合、コロンを含む
  ただの地の文として扱われる(誤って知らないキャラ名を書いてもエラーには
  ならず、静かにナレーション扱いになる点に注意)。
- 選択肢ブロック(`?` の直後)は `>` で始まる行が続く限り読み取られる。
  `>` 行の間に空行や他の行を挟むとブロックが終了してしまう。
- ラベルが存在しない `-> label名` やジャンプ先を指定するとエラーが送出される
  (`shared/domain/vm.ts` の `jumpTo()` 参照)。

台本フォーマット自体を拡張した場合は、この表と `parser.ts` 冒頭のコメントを
両方更新すること。
