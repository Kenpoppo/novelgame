# BGM/SE 素材ガイド

このエンジンは実音声ファイルをリポジトリにバンドルしない(ライセンス確認が
個別に必要になるため)。代わりに、状況に合った音源をここに挙げるサイトから
探してダウンロードし、エディタの「音源ライブラリ」パネルからアップロードして
使う運用にする。

## 優先して使うサイト(クレジット表記不要)

- **[DOVA-SYNDROME](https://dova-s.jp/)** — 国内最大級のフリーBGMサイト。
  約19,000曲、オールジャンル対応。クレジット表記不要・商用利用可。
  BGM探しはまずここから。
- **[効果音ラボ](https://soundeffect-lab.info/)** — フリー、商用利用無料、
  クレジット表記・報告不要の効果音(SE)サイト。業務用途でも使われる品質。
  SE探しはまずここから。

## 補助的に使うサイト(クレジット表記が必要)

- **[OtoLogic](https://otologic.jp/)** — BGM/ジングル/効果音。無料利用には
  クレジット表記が必要(CCライセンス)。DOVA-SYNDROME/効果音ラボで見つから
  ない場合の候補。
- **甘茶の音楽工房** — 「明るい」「癒やし」等のイメージやジャンルから探せる
  BGMサイト。商用・非商用問わず無料だが、作品内でのクレジット表記が必要。

クレジット表記が必要なサイトの音源を使う場合は、ゲーム内のクレジット画面や
説明文に表記を忘れないこと(現時点でエディタにクレジット表示機能はない —
必要になったら追加を検討する)。

## シチュエーション別の探し方

音源ライブラリに登録する際の「参照メモ」欄に、下記のような検索語を控えて
おくと後で探し直しやすい。

| シチュエーション | 検索キーワードの例 |
|---|---|
| 日常・学校 | 日常, 学校, のんびり, ほのぼの |
| 感動・切ない | 切ない, 感動, バラード, piano |
| 緊張・シリアス | 緊迫, サスペンス, ダーク, シリアス |
| コメディ・コミカル | コミカル, おかしい, ポップ, 8bit |
| 決断・選択肢の場面 | 決意, 静か, 緊張感, ミステリアス |
| 決定音(SEクリック系) | 決定, 選択, ボタン, カーソル |
| ページ送り音 | ページ, 紙, クリック |
| 場面転換 | 転換, ジングル, きらきら, シーン切り替え |

## 運用手順

1. 上記サイトでシチュエーションに合う曲/SEを探してダウンロードする。
2. エディタの「音源ライブラリ」パネルで種別(BGM/SE)・ラベル(シチュエーション名)
   を入力し、ダウンロードしたファイルをアップロードする(参照メモに検索語や
   出典サイト名を残しておくと後で差し替えやすい)。
3. 「ストーリー」パネルの各ビートで、登録した音源を BGM/SE ビートとして
   ストーリー中に配置する。
4. ファイルがまだ無い状態でもラベルとメモだけ登録してビートを組み立てられる
   (コンパイル時にエラーにはならず、単に再生がスキップされる)。詳細は
   [editor.md](./editor.md) の `compileProject` の項を参照。
